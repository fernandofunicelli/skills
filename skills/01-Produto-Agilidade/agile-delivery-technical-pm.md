# 🛠️ Agile Delivery & Technical PM (Elite Module)

Garantia de que a estratégia se traduz em código de alta qualidade entregue no prazo.

## 1. Definition of Done (DoD)
- Código revisado e aprovado.
- Testes unitários passando (>80% cobertura).
- Documentação técnica atualizada no Pillar `03-04`.
- Verificação visual (Stitch Match).

## 2. Requirement Engineering
- **User Stories:** Focadas no valor para o usuário (Como [persona], eu quero [ação], para que [resultado]).
- **Technical Specs:** Detalhamento de APIs, modelos de dados e restrições.
- **Acceptance Criteria (AC):** Critérios binários de sucesso.

## 3. Project Management
- **Scrum/Kanban:** Gestão de fluxo e remoção de impedimentos.
- **Cycle Time:** Velocidade de entrega do commit ao deploy.
- **Risk Mitigation:** Identificação precoce de gargalos técnicos.
