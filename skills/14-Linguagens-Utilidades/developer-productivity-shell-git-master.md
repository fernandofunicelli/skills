# 🛠️ Dev Productivity & Utilities (Elite Module)

Ferramentas e processos que multiplicam a eficácia e velocidade do desenvolvedor.

## 1. Advanced Git
- **Flow Control:** Rebase interactivo, cherry-picking estratégico e squash de commits.
- **Governance:** Mensagens de commit semânticas e revisões de código focadas em qualidade.

## 2. Shell & Automation
- **Bash / Zsh:** Automação de tarefas repetitivas e scripts de manutenção de sistema.
- **Terminal Efficiency:** Uso de aliases, filtros de busca (grep/awk/sed) e utilitários modernos (fd, ripgrep).

## 3. Context & Knowledge
- **Workflow Mastery:** Mantendo foco via gestão de tarefas (AGENTS.md).
- **Documentation:** READMEs vivos e auto-explicativos.
