# 🛠️ Web Scraping & Extraction (Elite Module)

Coleta massiva e estruturada de dados da web para alimentar sistemas de inteligência.

## 1. Browser Automation (Playwright)
- **Navigation & Interaction:** Simulação de fluxos complexos de usuário.
- **Wait Strategies:** Lógica baseada em estados de rede e seletores específicos.
- **Data Capture:** Extração via DOM, Screenshots e geração de PDF.

## 2. Firecrawl & LLM Extraction
- **Markdown Conversion:** Limpeza automática de HTML para formatos amigáveis a LLMs.
- **Smart Crawling:** Mapeamento e extração recursiva de domínios inteiros.

## 3. Anti-Bot Mastery
- **Proxy Rotation:** Uso de proxies residenciais para evitar rate limits.
- **Fingerprint Simulation:** Gestão de headers e User-Agents para parecer tráfego humano.
- **Content Structuring:** Validação de esquemas de saída com Zod para garantir consistência.
