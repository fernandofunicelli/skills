# 🛠️ DevOps & Cloud Infrastructure (Elite Module)

Automação e escalabilidade de ambientes através de infraestrutura como código.

## 1. Cloud Architecture (AWS / GCP / Azure)
- **VPC & Networking:** Subnets, Firewalls (Security Groups) e Load Balancing.
- **Compute & Storage:** Escolha estratégica entre instâncias (EC2), Serveless (Lambda) e Containers (ECS/EKS).
- **Cost Optimization:** FinOps para monitoramento e redução de desperdício Cloud.

## 2. Infrastructure as Code (IaC)
- **Terraform:** Declaração de infraestrutura resiliente e versionada.
- **Kubernetes (K8s):** Orquestração completa de containers, auto-scaling e self-healing.
- **Docker:** Criação de imagens leves e seguras.

## 3. CI/CD & Automation
- **GitHub Actions:** Automação de pipelines de build, teste e deploy.
- **GitOps:** Uso do Git como única fonte da verdade para o estado da infraestrutura.
- **Secret Management:** Vaulting seguro de chaves durante o processo de build.
