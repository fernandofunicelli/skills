# 🛠️ Database & Persistence (Elite Module)

Gestão de dados com integridade, durabilidade e performance máxima.

## 1. ORM Mastery
- **Prisma:** Esquemas declarativos, migrações seguras e Client fortemente tipado.
- **Drizzle:** ORM leve com performance near-native e suporte total a TypeScript.

## 2. Database Design & SQL
- **Indexing:** Criação de índices estratégicos para otimização de P99 latency.
- **Normalization vs Denormalization:** Critérios para performance de leitura vs consistência de escrita.
- **Advanced SQL:** CTEs, Window Functions e Query Optimization.

## 3. Durable Workflows (DBOS)
- **Once-and-only-once Execution:** Garantia de que funções críticas não falhem ou repitam indevidamente.
- **Transactional Consistency:** Gestão de estado ácido em workflows distribuídos.
